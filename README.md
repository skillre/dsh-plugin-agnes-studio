# @skillre/dsh-plugin-agnes-studio

> 状态：experimental · 实测 DSH `0.2.2-rc.1`（2026-11-11）

用 Agnes 的免费模型生成图片和视频，有两个入口：

- **侧栏看板**：在 DSH 左侧栏点「Agnes 工作室」。左侧是参数区（提示词、模型、分辨率、比例），
  右侧是结果画廊，两边各自滚动，生成按钮固定在参数区底部，不用滚动就能点到。
  分辨率、模式这类 2–4 选项用分段控件直接摊开，比例、时长这类大集合用带比例示意图的胶囊标签。
  点结果卡上的「查看大图」（或直接点缩略图）会在面板内放大查看：滚轮缩放、拖动平移、
  双击放大、Esc 或点背景关闭，多张图时用左右方向键连续翻看。看板不弹新窗口，也不跳出应用。
- **会话内工具**：直接说「画一张…」「生成一段…视频」，模型调用 `agnes_image` / `agnes_video`，
  图片作为真正的 DSH 图片块出现在对话里。

[English](README.en.md)

## 它能做什么

| 能力 | 模型 | 参数 |
|---|---|---|
| 文生图 / 图生图 / 多图合成 | `agnes-image-2.5-flash`（默认）、`2.1-flash`、`2.0-flash` | 分辨率档 `1K`/`2K`/`3K`/`4K`，比例 8 种，最多 8 张参考图 |
| 文生视频 / 首尾帧 / 参考素材 | `agnes-video-2.5`（默认）、`agnes-video-2.5-flash` | 720P–2K（Flash 固定 720P），比例 6 种，4–12 秒，可选 seed，首帧/尾帧/参考图/参考音频/参考视频 |

参数不是自由填写的：看板的下拉项由模型能力表生成，Host 在发请求前按同一张表校验。
选 `agnes-video-2.5-flash` 时分辨率只剩 720P，因为上游对该模型只接受 720P —— 这样 UI 永远不会
给出一个上游会以 HTTP 400 拒绝的值。

**结果可以接着改，改出来的版本叠在同一张卡片里。** 成功的结果卡片上有「继续编辑」：提示词、
模型、分辨率、比例和参考图会带回左侧表单，并且这张图会作为下一张的**参考图**（图生图）一起提交
—— 想改什么、要保留什么直接写进提示词即可。失败的卡片上有「调整后重试」：不必重打提示词，
原来的参数回到表单，改到满意再生成。

改出来的新版本**不另开一张卡**，而是叠在原条目上：卡片左上角显示「第 2 / 3 版」，最新的一版在
最上面，后面几版从上方露出**自己那张图的边缘**（不是灰色装饰条，一眼能看出还有别的图）。三种操作
互不冲突：

- **翻看**——鼠标在图上上下移动就在各版本间切换，只是预览，不改任何数据，移出后回到当前版本。
  切换是纯淡入淡出：所有版本早已加载好、卡片高度取各版本里最高的那个，所以翻看时卡片**不会闪、
  不会抖、不会变高变矮**，鼠标下的东西不会跑走。
- **固定**——点卡片下方那一排版本数字，就把某一版真正「钉」在这张卡上（移开鼠标也不变），它的
  查看 / 下载 / 继续编辑 / 删除也就都指向这一版；点「1」回到跟随最新版。
- **展开**——点「展开」把整条线拆成一张张独立卡片，每张都能单独操作，再点「收起」收回堆叠。

你改过几次，历史里看到的是一条「原图 → 修改版 → …」的线，而不是一堆看不出关系的卡片。

视频结果不在此列：上游没有在既有视频上编辑/续写的接口，「参考视频」要求公网可访问的 URL 且只有
付费的 `agnes-video-2.5` 支持，所以成功视频卡片只提供下载与删除；失败视频仍可「调整后重试」。

## 安装

**由用户**在 DSH Desktop Client 或 Web UI 的 **Plugins / 插件管理** 里选择来源并确认安装。
发布后输入 npm 包名（如 `@skillre/dsh-plugin-agnes-studio@0.1.0`）；未发布时可用已构建
`.tgz` 的绝对路径，但需先确认目标客户端接受该来源。

安装后到 **Plugins → 本插件 → 配置** 里确认 `enableTools` 为开（默认开），左侧栏就会出现入口。

### 配置 API Key

插件**不把密钥写进配置文件**。按以下顺序解析，每次调用都重新读取，所以换 key 不需要重启：

1. DSH 凭据服务里名为 `AGNES_API_KEY` 的记录（推荐）；
2. 环境变量 `AGNES_API_KEY`；
3. 都没有 → 看板显示「还没有配置 API Key」并禁用生成按钮，会话里的工具返回 `not-configured`。

在 <https://platform.agnes-ai.com> 创建免费 key（无需绑卡）。密钥只在 Host 侧使用，
不会发送到浏览器，也不会写进生成记录。

## 配置项

全部可选，在插件行的 `config` 里覆盖：

| 键 | 默认 | 说明 |
|---|---|---|
| `baseUrl` | `https://apihub.agnes-ai.com/v1` | Agnes API 根地址，不带结尾斜杠 |
| `credentialRef` | `AGNES_API_KEY` | 凭据服务里的记录名 |
| `apiKeyEnv` | `AGNES_API_KEY` | 凭据为空时回退的环境变量名 |
| `dataDir` | `''` → `$DSH_HOME/agnes-studio` | 生成记录索引与媒体文件目录（插件独占）。留空时跟随 DSH home，避免隔离 profile 写进用户真实目录 |
| `enableTools` | `true` | 是否注册 `agnes_image` / `agnes_video` 工具 |
| `historyLimit` | `200` | 保留多少条记录；超出时最旧的连同文件一起删除 |
| `imageTimeoutMs` | `360000` | 生图超时（上游建议 60–360 秒） |
| `videoTimeoutMs` | `900000` | 视频任务总超时，含排队 |
| `pollIntervalMs` | `2000` | 视频任务轮询间隔 |
| `retryAttempts` | `5` | 「持续重试」总尝试次数（含第一次）；`1` 关闭该功能，回到单次重试 |
| `retryBaseDelayMs` | `15000` | 第二次尝试前的等待，之后每次翻倍 |
| `retryMaxDelayMs` | `180000` | 退避上限，避免几分钟都不动一次 |

## 权限与副作用

- **网络**：只访问 `baseUrl`（默认 `apihub.agnes-ai.com`）以及它返回的媒体地址。
  第三方 CDN 的下载**不带** API Key。
- **文件**：只写 `dataDir`（默认 `$DSH_HOME/agnes-studio`），一个 `index.json` 加 `media/` 下的媒体文件。
  文件名是随机 UUID；读取时再校验一次 id 形状，路径穿越不可达。
- **密钥**：只经凭据服务或环境变量读取；不写日志、不进生成记录、不发给浏览器。
- **浏览器**：看板通过 DSH Connection 的 `/api` 路由通信，走同一套 Host/Origin 与登录态校验；
  生成的媒体也经同一道栅栏提供，不是公开可读。

## 数据与清理

生成记录在 `$DSH_HOME/agnes-studio`（通常是 `~/.dsh/agnes-studio`）：

```sh
# 删除全部生成记录与文件（等价于看板的「清空全部」）
rm -rf ~/.dsh/agnes-studio
```

看板里单条删除、清空全部都会同时删掉索引项和磁盘文件。

`dataDir` 留空（默认）时跟随 `$DSH_HOME`，只有在 `DSH_HOME` 未设置时才回退到 `~/.dsh` ——
这样在隔离或自定义 home 的 profile 里，数据不会落进用户真实安装目录。

见 [UNINSTALL](UNINSTALL.md)。卸载插件不会自动删除 `~/.dsh/agnes-studio`；

## 后台任务与提示词优化

- **任务在 Host 上跑，不占用看板。** 生成请求提交后 Host 立刻返回，任务在 Host 里继续；
  切换面板、切到别的页面、甚至刷新整个 Web 页面，任务都不会中断。回到看板时，正在跑的任务
  从 Host 的 `state.running` 读出来继续显示（含进度条与「取消」），跑完后自动变成结果卡片。
  之前「任务没中断但回来什么都看不到」是因为在跑标记只存在客户端组件里，组件卸载就没了。
  还没有记录的**新任务**在画廊里占一张占位卡，并在参数区上方显示后台提示条；重试不吃这一套，
  见下一条。
- **重试按记录 id 走 Host**。点击失败卡片的「重试」是把记录的 id 交给 Host，由 Host 用**这条
  记录自己保存的原始请求**重新发起 —— 不依赖看板内存里「上次提交了什么」，所以离开再回来、
  刷新页面之后重试同样有效（实测整页刷新后重试仍能发起任务）。重试会**原地更新**那一行，
  不会每点一次就多一条失败记录；进度也显示在**这张卡片自己**里（转圈 +「正在重试，完成后会
  更新这条记录」+「取消」），不会在旁边多出一张「新任务」卡片再等它合并，也不会重复出现在
  后台提示条里。
- **持续重试：队列满时不用一直点。** 免费版视频队列会连续几分钟返回「队列已满」，手动点一次重试
  通常还是撞在同一堵墙上，用户最后只能反复点。失败卡片因此多了一个「持续重试」：Host 会按
  15s → 30s → 60s → 120s → 180s（封顶）的退避自己重排，最多 5 次，期间卡片显示「第 2 / 5 次
  尝试」和「N 秒后自动重试」倒计时；这一段等待发生在 Host，**关掉看板或刷新页面都不会中断**，
  回来继续看到进度。只重试**可能自愈**的失败（队列满、限流、5xx、超时、下载中断）；参数错、
  余额不足、Key 无效这类确定性失败一次就报出来，不会白等。中途可以「取消」。重试次数与退避
  间隔可配置（`retryAttempts` / `retryBaseDelayMs` / `retryMaxDelayMs`），`retryAttempts: 1`
  即关闭该功能、回到单次重试。最终结果只写**一条**记录，并标出「共尝试 N 次」。
- **继续编辑与调整后重试**。点成功图片卡片的「继续编辑」时，看板把这条记录的原始请求
  （提示词、模型、分辨率、比例、参考图）回填到左侧表单，并在表单顶部显示来源缩略图；提交时
  Host 从磁盘读出这张图的字节，内联成 `data:` URI 作为图生图的参考图发给上游 —— 生成的图片走
  的是同源鉴权路由，上游取不到它，所以内联发生在 Host 侧，浏览器只传「用哪条记录」。
  点失败卡片的「调整后重试」只回填提示词与参数（失败任务没有产物可当参考图），改完按新记录重跑。
  两种操作都不复用原记录 id：原记录留着，新记录带 `derivedFrom` 与「承接 …」标记；如果源记录
  在提交前被删掉，Host 会当场拒绝并说明原因，不会留下无法解释的失败卡。
- **提示词优化**：提示词框里的「优化提示词」调用 Agnes 的文字模型（`agnes-3.0-flash`）把草稿
  写得更具体，按生图/生视频给不同建议（生图补构图、光比、镜头；生视频补运动、运镜、节奏），
  并保持你原来的语言与主体。改写后可点「撤销」回到原文；继续手动编辑即视为接受。
- **取消**：在跑的任务可以在看板上直接取消，取消不会留下失败记录。

## 已知限制

- 视频是**异步**任务：提交后 Host 轮询上游直到完成。队列满时上游返回 HTTP 503
  `video_queue_full`，看板会明确说明这是上游并发容量限制（不是参数问题）并标为「可重试」。
  实测该状态可连续持续数分钟，属于上游侧排队，不是插件故障。
- 账户余额不足时上游返回 403 `insufficient_user_quota`，插件会报成「余额不足」并说明 Key 本身
  有效 —— 不会误报成「API Key 无效」。付费视频模型（`agnes-video-2.5`）会消耗额度，
  `agnes-video-2.5-flash` 是免费的但共享队列。
- 参考素材必须是**公网可访问**的 HTTPS 地址或 `data:` URI。localhost、内网地址、明文 HTTP
  在发请求前就被拒绝 —— 上游自己去取素材，这类地址只会延迟失败。
- **视频结果不支持「继续编辑」**：上游视频接口只有文生视频、首尾帧和参考素材三种模式，没有在
  既有视频上编辑、续写或重混的能力；唯一的「参考视频」输入要求公网可访问的 URL，且只有付费的
  `agnes-video-2.5` 接受。本插件把结果存在本地、用同源鉴权路由提供，没有把本地视频变成公网地址的
  通道，所以成功视频卡片只有下载与删除；失败视频仍可「调整后重试」。
- 图片「继续编辑」把结果内联成 `data:` URI 作为参考图，不需要图片公网可访问；代价是请求体会随
  原图尺寸增大（1K 约 2 MiB，4K 可达 20 MiB 以上）。上游对超大请求可能拒绝，表现为普通失败，
  可换低分辨率档位后重试。
- `agnes-video-2.5-flash` 不支持参考视频，且最多 5 张参考图（`2.5` 是 8 张）。
- 生成记录是**本地**的，不跨设备同步；`historyLimit` 之外的最旧记录会被删除。
- 看板一次只跑一个任务（避免重复提交造成重复计费与排队加深）。任务在后台运行期间表单保持
  禁用，点「取消」可以结束它。
- 图片查看器只在**面板内**放大，不会打开系统图片查看器或新窗口：生成图是本地存储、
  靠会话鉴权访问的，交给外部程序既会 401 也会绕开 DSH 的窗口策略。视频仍在卡片里就地播放，
  查看器只处理图片。
- 同一 `dataDir` 只应由一个插件实例使用：索引写入在单个 handle 内串行化，两个实例指向同一目录
  仍可能互相覆盖。
- 图片以 DSH 附件形式进入对话；视频以同源 URL 返回，在对话里给出可打开的位置，
  不是视频块。
- Agnes 的免费额度、模型清单与参数上限由上游随时调整；本插件按 2026-11-11 的实测契约实现，
  上游新增能力需要更新插件。
